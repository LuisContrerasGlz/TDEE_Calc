# TDEE_Calc

This tool analyzes your unique biometric data to estimate exactly how many calories you burn each day, providing essential insights into your BMR, BMI, and personalized macronutrient targets to help you optimize your nutrition.

With this information, you know how many calories are needed to maintain, cut or bulk depending on your goals.

System in metric.

## How it works

The user inputs basic information including gender, age, weight, height, and activity level. An optional body fat percentage can also be provided for more accurate estimations.

Once the data is submitted, the application calculates:

- Basal Metabolic Rate (BMR)
- Total Daily Energy Expenditure (TDEE)
- Caloric targets for a 15% deficit (cut)
- Caloric targets for a 15% surplus (bulk)
- Suggested macronutrient distribution (protein, fats, carbohydrates)

The results are displayed immediately on screen.

## Export feature

After calculating, the user has the option to download the results as a `.txt` file. This file includes all calculated values and macro recommendations, making it easy to store, track progress, or share the information.

## Technologies

This is a simple front-end application built using:

- HTML
- CSS
- JavaScript

## Use cases

- Individuals tracking calories for fat loss, maintenance, or muscle gain  
- Fitness enthusiasts looking for quick macro estimates  
- Basic nutrition planning without external tools  

## Notes

All calculations are estimates based on standard formulas and should be used as a reference, not as a substitute for professional medical or nutritional advice.
